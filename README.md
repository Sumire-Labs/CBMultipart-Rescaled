# CBMultipart Rescaled

CBMultipart / Forge Multipart rebuilt for Cleanroom, Java 25, and Scala 3.
It dynamically handles different functional parts within a single block space,
including microblocks.

## Requirements

- Cleanroom 0.7.14 or newer
- Scalar 3.9.0 or newer
- CodeChicken Lib CRE 3.3.10 or newer

## For Developers

Maven repository: [Sumire Labs Maven](https://artifact.sumirelabs.com/maven/releases)

Maven coordinates:

```text
codechicken:CBMultipart-Rescaled:<version>
```
